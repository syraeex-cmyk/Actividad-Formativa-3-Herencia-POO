## Descripción
Proyecto de ejemplo que aplica herencia en Java mediante una clase base `Empleado` y dos clases derivadas: `EmpleadoTiempoCompleto` y `EmpleadoPorHoras`.

## Archivos
- `Empleado.java`: clase base con atributos y métodos comunes.
- `EmpleadoTiempoCompleto.java`: subclase que calcula sueldo mensual.
- `EmpleadoPorHoras.java`: subclase que calcula pago por horas trabajadas.
- `Main.java`: crea objetos y prueba métodos heredados y propios.

## Ejecución
Compilar los archivos Java y ejecutar la clase `Main`.
